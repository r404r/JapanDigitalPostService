# task-0007 — React sample 查询页、同步状态页与 token 发行界面

- 状态: 完成
- 依赖: task-0005, task-0006, task-0008
- 阶段: 前端

## Goal

实现最小可用 React sample 页面，覆盖地址查询、同步状态/历史查看，以及 token 发行/管理基本流程。

## 完成内容

- `web/` 引入 Vite + React + TypeScript。
- 查询页支持邮编、都道府県、市区町村、关键字查询。
- 查询结果展示 OpenAPI 字段 `total_count`、`returned`、`items`，并展示 `items.length` 作为本次返回地址数量。
- 对 timeout、认证失败、结果过多、0 结果、服务错误提供清晰 UI 状态。
- 同步页展示 `total_addresses`、运行状态、最近成功同步和历史运行记录的 `rows_total` / 错误摘要，并支持 admin 手动触发 full/diff。
- Token 页支持发行、脱敏列表、吊销；明文 token 只在发行成功后展示一次。
- API client 集中维护在 `web/src/api/client.ts`，与 `api/openapi.yaml` 保持字段契约一致。
- 关键交互由 `web/src/App.test.tsx` 覆盖。

## 验证

```bash
make web-test
make web-build
```

浏览器联调流程：启动后端后执行 `make web-dev`，访问 `http://localhost:5173`，输入 Bearer token 后验证 查询 -> 同步状态 -> token 发行/列表/吊销。
