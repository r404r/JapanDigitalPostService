# JapanDigitalPostService API v1

本文件是 `/v1` API 的人读版规格。机器契约以 [`../../api/openapi.yaml`](../../api/openapi.yaml) 为准；两者必须保持一致。

## 通用约定

| 项 | 说明 |
|---|---|
| Base URL | `/v1` |
| Content-Type | 请求/响应 JSON 均使用 `application/json`，`DELETE /tokens/{id}` 成功时无响应体 |
| 认证 | 除 `GET /health` 外，所有 API 均使用 `Authorization: Bearer <token>` |
| Scope | `read` 可访问查询与同步状态；`admin` 隐含 `read`，并可触发同步和管理 token |
| 明文 token | 仅 `POST /tokens` 创建时返回一次；持久化时只保存 hash 与 prefix |
| 可选响应加密 | `PAYLOAD_ENCRYPTION=aes-gcm` 时，JSON 响应带 `X-Payload-Encryption: AES-256-GCM`，body 为 AES-GCM 信封 |
| 请求追踪 | 服务端会回写 `X-Request-Id`；错误响应可包含 `trace_id` |

### 可选响应加密

默认 `PAYLOAD_ENCRYPTION=none` 时，各端点按下文 schema 返回明文 JSON。开启
`PAYLOAD_ENCRYPTION=aes-gcm` 后，服务端只封装 **JSON 响应体**，HTTP 状态码、鉴权规则与端点语义不变；
客户端需先按响应头 `X-Payload-Encryption: AES-256-GCM` 解开信封，再按下文 schema 解析明文 JSON。

信封格式：

```json
{
  "enc": "AES-256-GCM",
  "kid": "optional-key-id",
  "nonce": "base64 nonce",
  "ciphertext": "base64 ciphertext with GCM tag"
}
```

客户端使用约定的 base64(32B) `PAYLOAD_ENC_KEY` 和 `kid` 对应密钥解密；认证失败、nonce 或密文非法时拒绝该响应。
非 JSON 响应与空 body 原样透传。请求体不做应用层加密，传输层仍依赖 TLS。

## 错误响应

统一错误体：

```json
{
  "status": "invalid_request",
  "message": "human readable message",
  "trace_id": "request-id"
}
```

`status` 取值：

| status | 常见 HTTP | 含义 |
|---|---:|---|
| `invalid_request` | 400 | 参数、路径、JSON body 或字段值非法 |
| `unauthorized` | 401 | 未提供 token、token 无效、过期或已吊销 |
| `forbidden` | 403 | token 有效但 scope 不足 |
| `not_found` | 404 | 资源不存在，例如未知 token id 或邮编零命中 |
| `timeout` | 504 | 查询超时 |
| `sync_running` | 409 | 已有同步在运行，拒绝并发触发 |
| `internal_error` | 500 | 服务内部错误 |
| `rate_limited` | 429 | 预留状态，当前实现未默认启用 |

401 错误不会区分具体原因，也不会回显 token、hash、内部栈或配置。

## 数据模型

### Address

| 字段 | 类型 | 说明 |
|---|---|---|
| `zipcode` | string | 7 位邮编 |
| `jis_code` | string | 全国地方公共团体代码 |
| `prefecture` | string | 都道府県 |
| `prefecture_kana` | string | 都道府県カナ |
| `city` | string | 市区町村 |
| `city_kana` | string | 市区町村カナ |
| `town` | string | 町域 |
| `town_kana` | string | 町域カナ |

### SearchResult

| 字段 | 类型 | 说明 |
|---|---|---|
| `status` | `ok` \| `too_many_results` | 查询成功体状态。参数非法、认证失败、超时等返回错误体 |
| `total_count` | integer | 满足条件的总命中数 |
| `returned_count` | integer | 本次实际返回条数 |
| `truncated` | boolean | `total_count > returned_count` 时为 `true` |
| `address_count` | integer | 仅 `GET /addresses/{zipcode}` 返回，表示该邮编地址条数 |
| `items` | Address[] | 地址列表 |

### SyncStatus

| 字段 | 类型 | 说明 |
|---|---|---|
| `total_addresses` | integer | 当前地址表总数 |
| `running` | boolean | 是否有同步运行中 |
| `last_success_at` | string(date-time) \| null | 最近成功同步完成时间 |
| `last_type` | `full` \| `diff` \| null | 最近成功同步类型 |

### SyncRun

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 同步运行 ID |
| `type` | `full` \| `diff` | 实际同步类型。`auto` 只作为触发入参，不落库 |
| `status` | `running` \| `success` \| `failed` | 运行状态 |
| `trigger` | `schedule` \| `manual` | 触发来源 |
| `source_url` | string | 下载来源 URL |
| `file_checksum` | string | 下载 zip 的 SHA-256 |
| `file_size` | integer | 下载 zip 字节数 |
| `diff_period` | string \| null | 差分目标月份 `YYMM`，diff 专用 |
| `rows_added` | integer | 新增行数 |
| `rows_updated` | integer | 更新行数 |
| `rows_deleted` | integer | 删除行数 |
| `rows_total` | integer | 处理行数 |
| `started_at` | string(date-time) | 开始时间 |
| `finished_at` | string(date-time) \| null | 完成时间，运行中为空 |
| `duration_ms` | integer | 耗时毫秒 |
| `error_message` | string \| null | 失败详情 |

### TokenInfo

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | token ID |
| `name` | string | 人类可读名称 |
| `prefix` | string | 明文前 8 位，便于识别，不可反推 |
| `scope` | `read` \| `admin` | 权限 |
| `created_at` | string(date-time) | 创建时间 |
| `expires_at` | string(date-time) \| null | 为空表示永不过期 |
| `last_used_at` | string(date-time) \| null | 最近使用时间 |
| `revoked_at` | string(date-time) \| null | 吊销时间 |
| `token` | string | 仅 `POST /tokens` 创建响应返回一次 |

## GET /addresses

按邮编、都道府県、市区町村或关键字查询地址。至少提供一个过滤条件。

### Query

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| `zipcode` | string | 否 | 7 位时精确匹配，否则前缀匹配 |
| `prefecture` | string | 否 | 都道府県名，模糊匹配 |
| `city` | string | 否 | 市区町村名，模糊匹配 |
| `q` | string | 否 | 跨字段模糊关键字，覆盖汉字与カナ字段 |
| `limit` | integer | 否 | 默认 20，硬上限 20 |
| `offset` | integer | 否 | 默认 0，仅 `total_count <= MAX_TOTAL` 时用于分页 |

用户输入中的 `%`、`_`、`\` 会按字面量转义。

### Response

`200 OK`

```json
{
  "status": "ok",
  "total_count": 134,
  "returned_count": 20,
  "truncated": true,
  "items": [
    {
      "zipcode": "1000001",
      "jis_code": "13101",
      "prefecture": "東京都",
      "prefecture_kana": "トウキョウト",
      "city": "千代田区",
      "city_kana": "チヨダク",
      "town": "千代田",
      "town_kana": "チヨダ"
    }
  ]
}
```

### Status

| HTTP | status | 说明 |
|---:|---|---|
| 200 | `ok` | 成功，零命中时 `items: []` |
| 200 | `too_many_results` | 命中数超过 `MAX_TOTAL`，返回前 `FUZZY_LIMIT` 条并提示收窄条件 |
| 400 | `invalid_request` | 无过滤条件、邮编非数字、limit/offset 非整数等 |
| 401 | `unauthorized` | token 缺失或无效 |
| 403 | `forbidden` | scope 不足 |
| 504 | `timeout` | 查询超时，不返回部分数据 |

## POST /sync/trigger

手动触发同步。该接口只接受 admin token，异步执行并立即返回 `running` 记录。

### Request

```json
{
  "type": "auto"
}
```

| 字段 | 类型 | 必须 | 说明 |
|---|---|---|---|
| `type` | `auto` \| `full` \| `diff` | 是 | `auto` = 地址表为空时 full，否则 diff；`full` = 强制全量；`diff` = 强制差分 |

落库的 `SyncRun.type` 始终是 `full` 或 `diff`，`auto` 不作为运行类型落库。

### Response

`202 Accepted`

```json
{
  "id": "run-id",
  "type": "full",
  "status": "running",
  "trigger": "manual",
  "rows_added": 0,
  "rows_updated": 0,
  "rows_deleted": 0,
  "rows_total": 0,
  "started_at": "2026-06-11T09:56:56Z",
  "finished_at": null,
  "duration_ms": 0,
  "error_message": null
}
```

### Status

| HTTP | status | 说明 |
|---:|---|---|
| 202 | - | 已接受，异步运行中 |
| 400 | `invalid_request` | body 非法或 type 不是 `auto/full/diff` |
| 401 | `unauthorized` | token 缺失或无效 |
| 403 | `forbidden` | 非 admin token |
| 409 | `sync_running` | 已有同步运行中 |

## POST /sync/upload

管理者が日本郵政 `utf_ken_all` の zip または解凍済み UTF-8 csv をアップロードし、全量同期として取り込む。差分同期には使わない。同期ロックは schedule/manual と共通で、実行中は `sync_running` を返す。

### Request

`multipart/form-data`

| 字段 | 类型 | 必须 | 说明 |
|---|---|---|---|
| `file` | binary | 是 | `.zip` または `.csv`。zip 内の最初の `.csv` を読み込む。Shift-JIS は非対応。 |

### Response

`200 OK`

```json
{
  "id": "run-id",
  "type": "full",
  "status": "success",
  "trigger": "upload",
  "source_url": "upload:utf_ken_all.zip",
  "file_checksum": "sha256...",
  "file_size": 123456,
  "diff_period": null,
  "rows_added": 1000,
  "rows_updated": 0,
  "rows_deleted": 0,
  "rows_total": 1000,
  "started_at": "2026-06-11T09:56:56Z",
  "finished_at": "2026-06-11T09:57:30Z",
  "duration_ms": 34000,
  "error_message": null
}
```

### Status

| HTTP | status | 说明 |
|---:|---|---|
| 200 | - | 取り込み完了 |
| 400 | `invalid_request` | multipart / file フィールド / サイズが不正 |
| 400 | `unsupported_file` | `.zip` / `.csv` 以外 |
| 401 | `unauthorized` | token 缺失或无效 |
| 403 | `forbidden` | 非 admin token |
| 409 | `sync_running` | 已有同步运行中 |
| 422 | `unzip_failed` | zip 解凍失敗 |
| 422 | `csv_format_error` | UTF-8 でない、または utf_ken_all 形式でない |
| 500 | `internal_error` | 解析後の DB 取り込み失敗 |

## GET /admin/settings

读取管理画面可配置、重启后保留的运行时抓取设置。只接受 admin token。

每项含 `value`（当前有效值）、`default`（默认值，「恢复默认」回退到此）、`overridden`（是否存在 DB 覆盖）。有效值优先级 **DB 覆盖 > env > 代码默认**（见 [architecture §9.1](../architecture.md)）。

### Response

`200 OK`

```json
{
  "download_max_retry": { "value": 3, "default": 3, "overridden": false },
  "scrape_full_url": {
    "value": "https://www.post.japanpost.jp/service/search/zipcode/download/utf/zip/utf_ken_all.zip",
    "default": "https://www.post.japanpost.jp/service/search/zipcode/download/utf/zip/utf_ken_all.zip",
    "overridden": false
  }
}
```

### Status

| HTTP | status | 说明 |
|---:|---|---|
| 200 | - | ok |
| 401 | `unauthorized` | token 缺失或无效 |
| 403 | `forbidden` | 非 admin token |

## PUT /admin/settings

更新运行时抓取设置（部分更新）。只接受 admin token。省略字段保持不变；`reset_to_default` 列出的键删除其覆盖值以恢复默认（对应画面「恢复默认」按钮）。同一键不可同时设值与重置。

### Request

```json
{
  "download_max_retry": 5,
  "scrape_full_url": "https://www.post.japanpost.jp/service/search/zipcode/download/utf/zip/utf_ken_all.zip",
  "reset_to_default": []
}
```

| 字段 | 类型 | 必须 | 说明 |
|---|---|---|---|
| `download_max_retry` | integer（0–10） | 否 | 设置重试次数覆盖值 |
| `scrape_full_url` | string | 否 | 设置全量 URL 覆盖值（必须 `https` 且属 `post.japanpost.jp` / `www.post.japanpost.jp`） |
| `reset_to_default` | string[] | 否 | 恢复默认的键：`download_max_retry` / `scrape_full_url` |

**校验**（失败返回 `400 invalid_request`，`message` 为日语提示）：

- `download_max_retry` 越界 → 「リトライ回数は 0 以上 10 以下の整数で指定してください。」
- `scrape_full_url` 非 https → 「URL は https で指定してください。」
- `scrape_full_url` 非官方域名 / 含用户名 → 「URL のドメインは日本郵便の公式サイト（post.japanpost.jp）のみ許可されています。」等
- 同一键既设值又出现在 `reset_to_default` → 「同じ項目を更新と既定値リセットの両方に指定できません。」

### Response

`200 OK` — 返回与 `GET /admin/settings` 相同结构的应用后视图。

### Status

| HTTP | status | 说明 |
|---:|---|---|
| 200 | - | 更新成功 |
| 400 | `invalid_request` | body 非法或校验失败（`message` 为日语提示） |
| 401 | `unauthorized` | token 缺失或无效 |
| 403 | `forbidden` | 非 admin token |
